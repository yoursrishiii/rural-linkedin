# GramWork / Rural LinkedIn

A friendly, hyperlocal job platform for rural workers and daily-wage labourers.

## Features

- Hyperlocal jobs with district and distance information
- Rural job categories including farming, construction, driving, and domestic work
- Voice assistant entry point for easier searching
- Community district forum
- Worker profile with skills, ratings, earnings, and certificates
- Direct chat with employers

## Run locally

    npm install
    npm run dev:client

The development server runs on port 5000.
